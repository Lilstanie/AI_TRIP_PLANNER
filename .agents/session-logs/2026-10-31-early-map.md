# The map opens while a plan loads when Where is filled in

## What changed

- `useTripPlaces` takes a pending destination; `useWorkspace` passes the draft's while a turn runs.
- `WorkspaceView` shows the map for that destination before a plan exists.
- `new-chat` E2E covers both a known and an unknown destination.

## Why

The Think row already reports real progress, so the status text stayed as it is. A destination
written only in the message reaches the browser with the finished plan, and sending it earlier
needs a shared contract change, which Joey chose not to make.
