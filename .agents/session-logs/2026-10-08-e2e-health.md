# Fix the red timeline E2E and let E2E scripts declare the keys they need

## What changed

- `apps/web/tests/e2e/timeline.e2e.mjs`: the place routes' "no Google key" answer is 503 (since
  commit 2ca5570), but the script only tolerated 502. It now treats 502 and 503 alike as "places
  unavailable", so the 503 console errors are expected again and the map-key route-check skip fires
  instead of waiting 20s for a "Use …" button that never comes.
- `apps/web/tests/e2e/run.mjs`: a `// requires-env: KEY[, KEY]` header line makes the runner report
  `skipped: needs KEY` instead of running the script. Skips are recorded in the summary JSON and do
  not change the exit code; failures still do. A malformed line is a runner error.
- `plan-quality` and `conversation-scope` declare `DEEPSEEK_API_KEY`.
- `docs/development.md` and `.zh.md`: one paragraph describing the convention.

## Why

The app is right: a missing key is permanent, and #2ca5570 deliberately answers 503 rather than a
retryable 502 (documented in `docs/api.md`). The script's expectation was stale. Both symptoms in the
retro had this one cause. `plan-quality` and `conversation-scope` also fail under `DATA_MODE=mock`
(8/15 and a failed brief check), so the declaration is unconditional. The other scripts run on
fixtures or mock data; `leg-mode-choice` already skips its one model-dependent scenario itself.

## Validation

- Before: `pnpm --filter @trip/web e2e timeline` failed (503 console errors, then timeout).
- After: the same command passes; the route check reports `skip` (no map key in this environment).
- `e2e plan-quality conversation-scope` without a key: both skipped, no server started, exit 0.
- `e2e plan-quality reply-language`: skip plus ok, exit 0. A throwaway failing script beside a
  skipped one exits 1; the same skipped script with its key set runs; a bad line exits 2.
- `pnpm test:scripts` (26 pass), web typecheck, web lint, `verify:docs`, `verify:pairs`,
  `verify:protected`: see the final report for results.

- `pre-push-checks` was not changed: it only points at the runner and development.md.
