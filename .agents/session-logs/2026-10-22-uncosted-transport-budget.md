# Distinguish unknown transport costs from free fares

## What changed

- TripPanel displays uncosted transport as unknown, discloses missing fares and qualifies at/below-budget status.
- Published zero fares and legacy positive section estimates retain their amounts; over-budget warnings remain.
- Extended the existing budget breakdown browser journey; updated both workspace UI guides.

## Validation

- Before production edits, desktop EN/ZH fixtures reproduced zero estimates and unqualified within-budget status for missing fares.
- Initial browser attempts also exposed fixture navigation, locale and updated-tab selector errors; retained as failed runs.
- `DATA_MODE=mock USE_MOCK_TOOLS=true CHANNEL=chrome LABEL=after pnpm --filter @trip/web e2e budget-category-breakdown` passed 167/167 assertions, including 40 transport scenarios at 1440×1000 and 390×844, EN/ZH and a JPY unknown-cost case.
- `pnpm --filter @trip/web test` passed 642 tests in 57 files; web typecheck and lint passed.
- Docs, protected files, 28 translation pairs, 100 E2E artifacts and E2E selectors passed their verification commands.
- Integrated main's read-only delivery helper after those checks; application code was unchanged by that integration.

## Notes for the next person

- Screenshots and summary JSON are generated by the existing budget breakdown journey; no new test harness or shared contract.
