# P3.0 — identity and migration

Added optional activity IDs, placeId references, price verification flags, independent editVersion and typed editIssues. Legacy plans remain readable. Workspace assigns missing IDs once and persists them; position changes do not derive new IDs. Snapshot parsing migrates version 1 to 2 while preserving drafts, messages and existing storage keys. Invalid/future versions retain the existing P2 recovery behavior.

Validation: migration round-trip/identity tests, P0–P2 regression suite and typecheck passed. Supplier display payloads are separate React state; plans retain place references only for new Places integration.
