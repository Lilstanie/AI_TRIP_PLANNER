# Link GitHub tickets, branches and PRs to Jira by TP key

## What changed

- `.github/pull_request_template.md`: a `Jira:` line at the top.
- `docs/agents/issue-tracker.md` and `.zh.md`: a Jira section (one story per ticket, story format, key in
  ticket titles, branch names and PR titles, status moved by a Jira Automation rule).

## Why

Jira only sees issue keys written in text. Joey asked for the convention and approved the template change
in the project thread on 2026-10-24 ("模板也可以改"). Smart commits are left out because a typo fails
silently; an Automation rule keyed on the PR title is configured once in Jira.

## Validation

See the pull request body for the commands run and their results.

## Notes for the next person

The Jira Automation rule (PR merged moves the story to Done) has to be set up in Jira by a project admin.
