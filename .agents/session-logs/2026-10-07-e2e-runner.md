# One command runs E2E scripts against a server it starts and stops itself

## What changed

- `apps/web/tests/e2e/run.mjs`, run as `pnpm --filter @trip/web e2e <name...> [--prod]`: picks a free
  port, builds into its own dist slot (`.next-e2e`, `-2` to `-4`, listed in `apps/web/tsconfig.json`),
  runs the scripts from the repo root, stops only its own process group, writes
  `output/e2e/runner/<time>.json`. `playwright` 1.56.1 is now an `apps/web` dev dependency.
- `apps/web/package.json`: `dev` and `start` drop `-p 3000`, so `PORT` works (default still 3000).
- `pre-push-checks`: E2E and installable-app rows name the runner; new `apps/web/app/api/**` →
  `docs/api.md` row; a rule for resolving `.agents/translation-pairs.json` after a merge; the
  testing-approach paragraph now points at `AGENTS.md` instead of repeating it.
- `AGENTS.md`: dropped two lines that restated defaults (Joey asked for this file to change).
- `docs/development.md` (+ zh), `ui-verification`: commands now use the runner.

## Why

The 2026-10-07 retro (`/mnt/project-files/retro/2026-10-07-deepening-refactor-retro.md`, items 1, 3, 4
and 6) found 18% of agents' shell calls went on starting, probing and killing dev servers by hand.
