# Agent Lab 受控部署冒烟记录

请复制此模板记录由负责人执行的部署冒烟。记录中不得包含提供方凭证。

- 部署和环境：
- 冒烟日期和时间（UTC）：
- 已部署的 commit：
- 基准版本：
- 数据模式：live
- 场景 ID：
- 策略 ID：
- 本次冒烟获准的提供方调用上限：
- 按提供方统计的实际调用次数（若请求均未到达提供方，请填写 `none`）：
- 运行 ID：
- 每次运行的结果（complete、degraded、partial、stopped、refused）：
- 提供方返回的用量或不可用：
- 每次运行的延迟：
- 门控拒绝及原因：
- 已知限制或后续工作：

不得包含 API 密钥、请求授权头、旅客个人数据或原始提供方负载。仅附上支持结果判断所需的脱敏运行产物。
