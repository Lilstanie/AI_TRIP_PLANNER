# Trip home 动作栏

[English](trip-home-actions.md) | 中文

状态：已实现。

本设计扩展现有的 [Trip home](../workspace-ui.zh.md#layout)。该页面继续列出当前 Trip 的 Chat，
并读取 Trip 自己保存的 Plan。此次改动把五个行程动作移到右侧栏，打开任何动作时都不离开
Trip home。

<a id="layout"></a>

## 布局

桌面上选择 Trip 后进入 Trip home：主栏和右侧栏一起居中，两侧各内收 24px，整体最大宽度
1440px，保留宽敞的聊天区和地图。平板和手机继续使用完整宽度。

| 区域   | 内容                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 主栏   | Trip 标题与事实、根据方案生成的 AI 建议、关联到该 Trip 的所有 Chat，以及输入框 |
| 右侧栏 | 五张动作卡片，下面是嵌入的 Trip 地图                                           |
| 覆盖层 | 所选动作的右侧抽屉；覆盖右侧栏，并保留主栏可见                                 |

打开 Chat 会进入正常的 Chat 工作区，使用原有可调整的 Chat／地图分栏。Trip home 用于
选择聊天和管理行程，不再在首页内嵌对话。

<a id="chats-and-suggestions"></a>

## Chat 与建议

- Trip home 列出 `tripId` 等于当前 Trip 的所有 Chat。一个 Trip 可以有任意多个 Chat。
- 选择一条 Chat 后，直接进入正常 Chat 工作区，并保留与当前 Trip 的关联。
  首次发送和点击建议创建 Chat 后也进入同一个工作区。
- 首次非空发送会创建一个关联 Chat，并立即使用当前 Trip Plan 发送一次请求，没有独立的
  Start chat 操作。聚焦、输入、清空和空发送均不创建 Chat。Enter 发送、Shift+Enter 换行，
  输入法确认不发送；切换 Trip 会清除未发送的主页草稿。首次发送失败保留 Chat 和用户消息，
  重试复用两者。
- 首次发送后聚焦正常 Chat 输入框；对话使用自己的滚动区域，手机保留原有 Chat 标签导航。
- Chat 标题显示数量，每行显示来自用户消息的主题标题、本地化日期和进入方向，手动命名保持
  不变。打开旧 Chat 保留 Trip 的较新 Plan。
- 建议根据当前 Trip 的 Plan 生成。选择建议时，通过同一首次发送流程发送提示。建议、Ideas
  数量和 Ideas 列表共用未排期活动与餐厅建议的选择规则。
- 旅客关闭建议后，在这个 Trip 的 Plan 改变之前都保持关闭。新 Plan 可以重新产生建议。
  存储写满时仍对本次访问生效并报告持久化失败；null 或形状错误的关闭记录会被忽略，不改动
  Trip 数据。

<a id="actions"></a>

## 动作

动作卡片按以下顺序显示，每项标题前显示装饰图标。每张卡片打开对应抽屉；有数量时在标题同一行的右侧仅显示数字，
不再显示 stops 等单位或另起一行。底部输入框直接使用 Chat 的表面样式，外层布局容器不再
添加背景、边框或阴影。

| 动作             | 抽屉内容                                                                           | 交互                                                                             |
| ---------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Itinerary        | 与对话中相同的可编辑 Trip 视图，包含活动、航班、住宿、待保存编辑和 Undo            | 原位编辑；选择某天后地图聚焦到该天                                               |
| Ideas            | 未安排的活动和餐厅建议                                                             | 沿用现有行程编辑流程把项目安排到某天                                             |
| Bookings         | 航班、住宿，以及其他标记为已预订的行程项目                                         | 已预订项目独立分组，不按行程顺序排列                                             |
| Trip preferences | 该 Trip 的现有偏好编辑器                                                           | 修改沿用现有保存和重新规划行为                                                   |
| Calendar         | 仅针对当前 Trip 的周／月视图；定时活动与全天停靠点、航班和住宿分区显示，不编造时刻 | 选择活动打开共享 Itinerary 编辑器中的对应活动；选择某天打开 Itinerary 并聚焦地图 |

产品还没有真实的媒体模型，因此不加入 Media；动作集合也不加入 Receipts。

<a id="drawer-behavior"></a>

## 抽屉行为

- 桌面端打开动作时，面板位于仍留在 Trip home 右侧栏的 Trip 地图旁；地图宿主和画布始终挂在
  Trip home 下，因此打开面板不会重建第二个渲染器。
- 打开的面板内有五个标签，可在不关闭面板的情况下切换 Itinerary、Ideas、Bookings、Trip preferences
  和 Calendar。当前 Trip、Chat、选中天和未提交编辑在切换后仍然保留。
- 手机端使用同一个抽屉，全屏显示并从右侧滑入。
- 关闭按钮、Escape 和点击抽屉外部都会关闭抽屉，恢复 Trip home 滚动位置，并把焦点返回打开它的
  动作卡片。
- 嵌套时间编辑器和 Settings 各自保留优先于动作面板的 Escape／关闭顺序。
- 同时只打开一个 Trip 动作抽屉。
- 抽屉是带可见标题的带标签 dialog。内容保持键盘可达，不创建额外的页面历史记录。
- Bookings 保留现有非 AUD 估算／汇率提示。航班标题和排期无障碍名称在中英文界面都从翻译目录
  获取。
- Itinerary 与对话右上角 Trip 共用最新 Plan、活动身份、选中天、待保存编辑和 Undo 记录。
  在任一入口修改或撤销后，另一入口、Calendar 和地图立即一致；只有航班或住宿的日期显示为
  已预订，而不是空闲日。

<a id="phone-layout"></a>

## 手机布局

Trip home 改为单列，顺序如下：

1. 标题与事实。
2. 根据方案生成的建议。
3. 五张动作卡片。
4. Chat。
5. Trip 地图。
6. 输入框。

主页面只有一个滚动区域，底部输入框保持固定，因此聊天列表很长时发送按钮仍然可见。桌面端打开嵌入
Chat 后，该区域改为弹性列布局，由 Chat 自己滚动；列表态 Trip home 仍使用页面滚动。动作抽屉
全屏显示，关闭和焦点规则与桌面端相同。

<a id="boundaries"></a>

## 边界

- 保留现有 Trip home 入口、标题、事实、Rename 和 Delete 菜单、读取最新 Plan 的规则，以及
  Trip 与多个 Chat 的关联。
- 替换当前会跳到对话 Trip 面板、全局 Calendar 页面或 Preferences 编辑器的动作卡片。
- 增加 Ideas 和 Bookings 视图，不增加新的数据概念。
- 不把 Trip home 变成刷新后恢复的存储页面。
- 不加入 Media 或 Receipts。

<a id="acceptance"></a>

## 验收

浏览器 E2E 覆盖以下项目后才算完成：

- 至少有两个 Chat 的 Trip 会同时列出两条，并能打开所选的一条。
- 从 Trip home 发送消息会创建一个关联同一 Trip 的新 Chat。
- 五个动作卡片都在不离开 Trip home 的情况下打开对应抽屉。
- Trip 首页 Itinerary 与对话 Trip 显示相同活动、航班和住宿，并同步 Plan 编辑与 Undo。
- 桌面面板打开时与地图并排，且不丢失 Trip、Chat、选中天或编辑状态；
  手机抽屉占满屏幕。
- 关闭按钮、Escape 和点击外部都会把焦点返回打开抽屉的卡片；列表态 Trip home 还会恢复页面滚动。
- 面板内标签可在不关闭的情况下切换动作。
- 非 AUD 的 Bookings 显示估算提示；航班标题和排期名称保持翻译。
- Calendar 默认周视图，周／月切换保留选中的 Trip 日期，Previous 和 Next 不离开 Trip。选择活动会打开
  共享 Itinerary 编辑器中的对应活动；选择某天会打开聚焦该天的 Itinerary，并聚焦地图。
- 建议会把提示发送到关联 Chat；关闭建议后，刷新仍保持关闭，直到 Plan 改变。
- 桌面、平板和手机布局在中英文界面下都没有横向溢出。
