# ELEC5620 Stage 2 演示评分标准

[English](demo-marking-criteria.md) | 中文

以下是课程组给出的 Stage 2 演示评分标准，于 2026-10-29 原文照录并译为中文。只调整了排版：每个等级是表格中的一行。四项标准合计 20 分（7 + 4 + 4 + 5）。

<a id="comprehensiveness-of-functions-and-features-7-marks"></a>

## 功能与特性的完整性（7 分）

| 等级   | 描述                                                                                                                                  | 分值        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 优秀   | 所有功能均已完整实现，并经过充分测试，包括边界情况。用户体验流畅，没有明显问题。（7 分）                                              | 7 至 >5 分  |
| 良好   | 几乎所有功能均已实现并测试，仅有少量小问题。系统在主要使用场景下运行良好。（5 分）                                                    | 5 至 >3 分  |
| 合格   | 大部分关键功能已实现，并完成了基础测试，但仍存在一些问题或缺口。（3 分）                                                              | 3 至 >2 分  |
| 基础   | 部分基础功能已实现，但关键功能仍然缺失，系统可能存在严重缺陷或问题。测试很少。（2 分）                                                | 2 至 >0 分  |
| 不得分 | 许多关键功能缺失或存在严重缺陷。功能不完整，且没有自动化测试。（0 分）                                                                 | 0 分        |

/7 分

<a id="ai-agent-perception-decision-making-and-interaction-4-marks"></a>

## AI 智能体：感知、决策与交互（4 分）

| 等级   | 描述                                                                                                                                  | 分值        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 优秀   | AI 智能体已完全集成，显著改善了感知、决策与交互，并基于详细的反馈或数据做出了明显改进。（4 分）                                       | 4 至 >3 分  |
| 良好   | AI 智能体集成良好，明显改善了感知、决策与交互，并利用反馈进行了优化。（3 分）                                                         | 3 至 >2 分  |
| 合格   | AI 智能体对感知、决策与交互提供了基本支持，但效果有限。已根据反馈做出部分改进。（2 分）                                              | 2 至 >1 分  |
| 基础   | AI 智能体已集成，但对感知、决策或交互的影响有限或不稳定。（1 分）                                                                     | 1 至 >0 分  |
| 不得分 | AI 智能体效果差或不存在。（0 分）                                                                                                     | 0 分        |

/4 分

<a id="agile-development-experience-4-marks"></a>

## 敏捷开发经验（4 分）

| 等级   | 描述                                                                                                                                  | 分值        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 优秀   | 敏捷实践已全面融入，所有迭代都有详细记录，包括燃尽图、用户故事和反馈循环。团队协作良好，迭代改进明显。（4 分）                        | 4 至 >3 分  |
| 良好   | 敏捷实践应用得当，迭代清晰，文档良好，包括用户故事和反馈循环，但仍有进一步优化的空间。（3 分）                                        | 3 至 >2 分  |
| 合格   | 基本遵循敏捷原则，文档、迭代和反馈循环尚可，但仍需加强。（2 分）                                                                      | 2 至 >1 分  |
| 基础   | 应用了部分敏捷实践，但迭代和反馈循环薄弱，文档不完整。（1 分）                                                                        | 1 至 >0 分  |
| 不得分 | 几乎没有敏捷实践的证据。迭代和反馈循环记录很差或缺失。（0 分）                                                                        | 0 分        |

/4 分

<a id="incorporation-of-advanced-technologies-5-marks"></a>

## 先进技术的应用（5 分）

| 等级   | 描述                                                                                                                                  | 分值        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 优秀   | 先进技术（至少 6 项）已完全集成，大幅提升了系统性能、可扩展性和可维护性。技术选型恰当，并有数据支撑的明显性能提升。（5 分）            | 5 至 >4 分  |
| 良好   | 先进技术（至少 5 项）集成良好，显著提升了系统性能、响应时间或可扩展性，并有数据支撑。（4 分）                                          | 4 至 >3 分  |
| 合格   | 应用了部分先进技术（至少 3 项），但其潜力未充分发挥，对性能的影响有限。（3 分）                                                        | 3 至 >2 分  |
| 基础   | 先进技术（至少 4 项）使用恰当，改善了系统性能或可扩展性，但整体影响有限。（2 分）                                                      | 2 至 >0 分  |
| 不得分 | 先进技术使用有限或不相关，系统性能没有可衡量的提升。（0 分）                                                                          | 0 分        |

/5 分
