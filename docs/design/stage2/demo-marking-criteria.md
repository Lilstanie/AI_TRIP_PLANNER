# ELEC5620 Stage 2 demonstration marking criteria

English | [中文](demo-marking-criteria.zh.md)

These are the Stage 2 Demonstration criteria as the unit set them, copied verbatim on 2026-10-29. Only the layout has changed: each rating is a table row. The four criteria add up to 20 points (7 + 4 + 4 + 5).

## Comprehensiveness of Functions and Features (7 Marks)

| Rating        | Description                                                                                                                                                                                                                 | Points     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Excellent     | All features are fully implemented, with thorough testing, including edge cases. The user experience is smooth and free of noticeable problems. (7 Marks)                                                                  | 7 to >5 pts |
| Good          | Almost all features are implemented and tested, with only minor issues. The system works well for the main user scenarios. (5 Marks)                                                                                       | 5 to >3 pts |
| Satisfactory  | Most key features are implemented, and basic testing has been done, but there are still a few issues or gaps. (3 Marks)                                                                                                    | 3 to >2 pts |
| Basic         | Some basic features are implemented, but key functionalities are still missing, and the system may exhibit significant bugs or issues. Testing is minimal.(2 Marks)                                                        | 2 to >0 pts |
| No Marks      | Many key features are missing or there are serious bugs. The functionality is incomplete, and there is no automated testing. (0 Marks)                                                                                     | 0 pts      |

/7 pts

## AI Agent: Perception, Decision-making, and Interaction (4 Marks)

| Rating        | Description                                                                                                                                                                                                                 | Points     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Excellent     | The AI agent is fully integrated and significantly improves perception, decision-making, and interaction, with clear enhancements based on detailed feedback or data. (4 Marks)                                            | 4 to >3 pts |
| Good          | The AI agent is well integrated and noticeably improves perception, decision-making, and interaction, with feedback used for refinement. (3 Marks)                                                                          | 3 to >2 pts |
| Satisfactory  | The AI agent provides basic support for perception, decision-making, and interaction, though its effect is limited. Some improvements have been made based on feedback. (2 Marks)                                          | 2 to >1 pts |
| Basic         | The AI agent is integrated but has limited or inconsistent impact on perception, decision-making, or interaction. (1 Mark)                                                                                                 | 1 to >0 pts |
| No Marks      | The AI agent is poor or none. (0 Marks)                                                                                                                                                                                     | 0 pts      |

/4 pts

## Agile Development Experience (4 Marks)

| Rating        | Description                                                                                                                                                                                                                 | Points     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Excellent     | Agile practices are fully integrated, with detailed documentation of all iterations, burn-down charts, user stories, and feedback loops. Team collaboration is strong, and iterative improvements are evident. (4 Marks)    | 4 to >3 pts |
| Good          | Agile practices are well applied, with clear iterations and good documentation, including user stories and feedback loops, though there is room for further optimization. (3 Marks)                                        | 3 to >2 pts |
| Satisfactory  | Agile principles are mostly followed, with documentation, iterations, and feedback loops that could be strengthened. (2 Marks)                                                                                             | 2 to >1 pts |
| Basic         | Some Agile practices are applied, though iterations and feedback loops are weak, and documentation is incomplete. (1 Mark)                                                                                                 | 1 to >0 pts |
| No Marks      | There is little to no evidence of Agile practices. Iterations and feedback loops are poorly documented or missing. (0 Marks)                                                                                               | 0 pts      |

/4 pts

## Incorporation of Advanced Technologies (5 Marks)

| Rating        | Description                                                                                                                                                                                                                 | Points     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Excellent     | Advanced technologies (at least 6) are fully integrated, greatly improving system performance, scalability, and maintainability. The technologies are well chosen and show clear performance improvements, supported by data. (5 Marks) | 5 to >4 pts |
| Good          | Advanced technologies (at least 5) are well integrated, significantly enhancing system performance, response time, or scalability, supported by data. (4 Marks)                                                            | 4 to >3 pts |
| Satisfactory  | Some advanced technologies (at least 3) are applied, but their potential is not fully realized, with limited impact on performance. (3 Marks)                                                                              | 3 to >2 pts |
| Basic         | Advanced technologies (at least 4) are appropriately used, improving system performance or scalability, but with limited overall impact. (2 Marks)                                                                        | 2 to >0 pts |
| No Marks      | Limited or irrelevant use of advanced technologies, with no measurable improvement in system performance. (0 Marks)                                                                                                        | 0 pts      |

/5 pts
