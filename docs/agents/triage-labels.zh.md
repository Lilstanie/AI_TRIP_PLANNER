# 分流标签

这些技能使用五个规范分流角色。本文档将这些角色映射到本仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义                         |
| -------------------------- | -------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估此问题         |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息       |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给无人值守代理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                 |
| `wontfix`                  | `wontfix`            | 不会处理                     |

当技能提到某个角色时（例如“应用可交给无人值守代理的分流标签”），请使用此表中对应的标签字符串。

如需匹配实际使用的词汇，请编辑右侧一列。
