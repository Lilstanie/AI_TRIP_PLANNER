# Reused-place note in the fallback reply: failure inventory

Written before the code (TP-294). The fallback reply (no model reply) warns when one stop is planned on
several days. An 8-day mock trip printed nine copies of the same sentence.

- More than one reused stop still prints one sentence per stop.
- The single-stop sentence changes wording in English or Chinese.
- The combined note drops the count, so the traveller cannot tell how many stops repeat.
- Names beyond the first few are listed in full and the note grows with the trip.
- The day list of a named stop is lost or reordered.
- No reused stop still prints a note.
